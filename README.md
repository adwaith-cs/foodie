# 🍴 Foodie — Multi-Page Food Ordering Website

Foodie is a modern front-end food ordering website created using:

- HTML
- CSS
- JavaScript

No frameworks are required.

---

# 📁 Project Structure

Foodie/

├── index.html
├── menu.html
├── cart.html
├── checkout.html
├── success.html
├── style.css
├── script.js
└── README.md

# 💾 Local Storage

The website uses browser localStorage to store the cart.

This means that when the user moves between:

Menu → Cart → Checkout

the selected food items remain available.

# 🚀 Running the Website

## Method 1 — VS Code Live Server

1. Open the Foodie folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html.
4. Select:

Open with Live Server

---

## Method 2 — Browser

Simply open:

index.html

in your web browser.

# ⚠️ Important

This is a front-end demonstration project.

It does not currently connect to:

- Real restaurants
- Real payment gateways
- Real databases
- Real delivery services
- User authentication
- Restaurant management systems

These can be added later using a backend such as:

Node.js
Express.js
MongoDB
MySQL
Firebase
